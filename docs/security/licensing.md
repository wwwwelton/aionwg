# Licensing assessment

The project now uses the MIT License; the complete grant is in [`LICENSE`](../../LICENSE).
This license applies to AionWG project code only. Bundled and vendored components
retain their own notices and terms.

Existing notices include:

- `WinDivert-LICENSE.txt` for the bundled WinDivert materials.
- `third_party/wireguard-go/LICENSE` and `VENDORED.txt` for vendored WireGuard-go.
- Native Shugo compatibility sources under `native/`, which require their own attribution review before redistribution.

Before distributing a release, verify the selected WinDivert, Wintun, Bubble Tea
and native compatibility notices in the release package. This document is a
repository assessment, not legal advice or a replacement for those notices.
